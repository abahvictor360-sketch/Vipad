How to install

Windows
  1. Run Vipad-Setup-x64.exe.
  2. If SmartScreen shows “Windows protected your PC”, click More info → Run anyway (early builds aren’t code-signed yet).
  3. Finish the installer — Vipad appears in the Start menu and on your desktop.
macOS
  1. Open Vipad-mac-universal.dmg and drag Vipad into Applications.
  2. First launch: right-click Vipad → Open → Open. You only do this once.
  3. Allow microphone access when Vipad asks.
Linux
  1. AppImage: chmod +x Vipad-linux-x86_64.AppImage, then double-click it.
  2. Debian/Ubuntu: sudo apt install ./Vipad-linux-amd64.deb.
  3. If recording is silent, allow the microphone in your desktop’s privacy settings.
Android
  1. Open this page on your phone or tablet and tap Download the APK.
  2. Open the file. If asked, allow your browser to Install unknown apps.
  3. Tap Install, open Vipad, and allow the microphone on your first recording.
iPhone & iPad
  1. Open Vipad in Safari.
  2. Tap Share → Add to Home Screen → Add.
  3. Launch Vipad from your Home Screen — it runs full-screen and offline.

Install help

Android says “App not installed” or blocks the download

Allow your browser to install unknown apps (Settings → Apps → Chrome → Install unknown apps). If an older Vipad build is installed, uninstall it first, then install the new APK.

Windows SmartScreen warns about an unknown publisher

Click More info → Run anyway. Early builds aren’t code-signed yet; every installer is built automatically from the public source code.

macOS says the app “can’t be opened”

Right-click Vipad in Applications and choose Open, then confirm. You only need to do this once.

Will I lose my recordings if the app closes or crashes?

No. Vipad autosaves every file — and every recording while it is still recording — on your device. Reopen Vipad and your work is restored. Closed files stay recoverable for 30 days.
